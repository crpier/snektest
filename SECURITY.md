# Security policy

## Reporting a vulnerability

Email security reports to [crpier42@gmail.com](mailto:crpier42@gmail.com).
Include the affected version, impact, reproduction steps, and any suggested
mitigation. Do not open a public issue for an undisclosed vulnerability.

You should receive an acknowledgement within seven days. Please allow time for
a fix and coordinated disclosure before publishing details.

## Supported versions

Security fixes are made on the latest released version. Development snapshots
are supported only until their corresponding release is published.
